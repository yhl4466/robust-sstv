## 3. 通道顺序测试：**作废**（报告第 3 项）

```
order-RGB-rgb.png  (246946 B)
order-BGR-rgb.png  (246946 B)
order-RBG-rgb.png  (246946 B)
order-GRB-rgb.png  (246946 B)     ← 四张字节数完全相同
```

**四张图完全相同** → 我的 `order` 参数在 RGB 分支下**不起作用** ✗

```js
for (let k = 0; k < 3; k++) v[order[k]] = toGrey(planes[order[k]][y][x], lo, hi);
let R = v.R, G = v.G, B = v.B;      // ← 按角色取回，order 被抵消
```

**正确写法**应是 `R = toGrey(planes[order[0]]…)`、`G = toGrey(planes[order[1]]…)`、`B = toGrey(planes[order[2]]…)` ✗
→ "四种顺序相关都是 0.3694"是**我代码的恒等式**，不是测量 ✗ **AC3 作废。**

**发现方式值得记录**：不是靠复查代码，而是靠**四张输出图的字节数完全相同**这一廉价信号 ✓

**所以"品红/青条纹"不来自这四项中的任何一项** ✗

### 8.2 ⚠️ 但这个结论有一个必须声明的前提失效

**本诊断管线自身的自校验未达标** ✗

```
[自校验] 我们的合成 S1（真值已知）
  行间相关 0.9877 (应 ≈0.99)  ·  色边 44.4 (应 ≈0)  ·  灰度均值 126.9
  第 128 行 G 平面相对真值斜坡的平均频率误差 405.7 Hz（1 灰阶 = 3.14 Hz = 129 灰阶）
```

合成图是**灰度斜坡**（R=G=B）→ **色边本应 ≈ 0**，实测 **44.4** ✗；**频率误差 405.7 Hz = 129 灰阶** ✗
**行间相关 0.9877 高，只是因为偏差逐行一致** ✗ → **管线有系统性标度/符号偏差** ✗

**我的具体怀疑（未证实）**：鉴频器符号反向会把 1500..2300 镜像成 2300..1500，
**平均误差恰好 ≈400 Hz** ✓ 与实测 405.7 Hz 吻合 ✓
**但我没有验证它**，所以**不能据此宣称"§4–§6 的相对比较仍然成立"** ✗ ——
相对比较在"偏差对所有假设一致"的前提下才有效，而 §6 的偏移测试会改变采样位置、
**偏差可能随之改变** ✗ 这是我必须承认的局限 ✓
