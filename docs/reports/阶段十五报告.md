### 1.1 为什么改了 3 行而不是 1 行（如实说明）

任务约束写的是"只改 `index.html` 的一处 `<title>`"，而 AC2 要求"**四个页面的 `<title>` 风格统一**"。
这两条在字面上有冲突，原因是：

- 你给的 `index.html` 候选标题**都含"平台"**（`抗干扰 SSTV 解码平台` / `… · 首页`）
- 而另外两页当时写的是 `抗干扰 SSTV 解码 · 嵌入端`（**不带"平台"**）

若只改 `index.html`，结果会是一页写"解码**平台**"、另两页写"解码"，**风格反而不统一**，AC2 不达标。
因此我把三个应用页统一到项目自身的名称「**抗干扰 SSTV 解码平台**」（与 README 的一级标题一致），
固定格式为 `抗干扰 SSTV 解码平台 · <页面>`。

**`tech.html` 未改动**，两个理由：
1. 它的标题是**论文标题本身**（`一种面向真实退化信道的抗干扰 SSTV 音频解码方法 · 技术报告`），
   信息量高、不应降级为"平台 · 技术报告"；
2. `tech.html` 是**生成物**，改它的标题等于改生成器并重新生成，而你本轮明确要求"不改 tech.html 内容"。
