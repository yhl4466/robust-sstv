### 1.1 ★ 为什么 δ_GR 是伪影

**247/256 行落在 δ = −20 = 搜索边界** ✗ → **不可能是一个"测得"的位移** ✓
**机制**：`G−R` 的行内自相关 lag1 高达 **0.87**（§3）✗ 即该信号**由低频趋势主导** ✗
**对趋势主导的信号做零均值归一化互相关**，把一条上升的曲线与自身平移比较时，
**|δ| 越大重叠区越"对齐"** ✗ → **相关值随 |δ| 单调升高，峰值必然落在边界** ✓✓
**峰值相关 0.868 也印证趋势主导** ✓（真实内容相关不会这么高 ✓）

**→ 结论：δ_GR 的测量无效，需要先去掉趋势（差分/高通）再相关** ✓

### 1.2 δ_GB 是有效的

```
0:191   -1:36   1:21   2:5
```
**191/256 行在 δ = 0** ✓ 其余 ±1–2 px ✓ **均值为 0.06 px** ✓
→ **G 与 B 之间没有系统性像素偏移** ✓✓

## 4. 行内 / 列间自相关对比（报告第 4 项）—— **本轮核心**

```
  来源            σ(G−R)  σ(L)   σ(G−R)/σ(L)  G−R 沿x(lag1/2/4/8)         G−R 沿y(lag1/2/4/8)
  合成 S1（真值）    2.3    73.6       0.0319   -0.54/0.04/-0.13/-0.10   0.90/0.90/0.88/0.81
  phigros         94.7    65.3       1.4505    0.87/0.77/0.64/0.39      0.54/0.49/0.42/0.34
  phigros 补偿后     98.7    63.9       1.5450    0.88/0.79/0.68/0.48     0.60/0.54/0.46/0.37
  Robot36 参照     60.5    76.1       0.7952    0.55/0.40/0.26/0.17      0.15/0.07/0.03/0.02
```

### 4.1 读法

| 来源 | 沿 x lag1 | 沿 y lag1 | 含义 |
|---|---|---|---|
| **合成 S1** | −0.54 ✗ | 0.90 | `σ(G−R)=2.3` **近零信号** → 两个数值都无意义 ✗（**仅证明管线不造假色度** ✓）|
| **Robot36 参照** | **0.55** | **0.15** | **真实图像的色度：沿行内中等相关、沿行间几乎不相关** ✓✓ |
| **phigros** | **0.87** ✗ | **0.54** ✗ | **两个方向都远高于参照** ✓ |

### 4.2 ★ 结论

**我们的"颜色"在两个方向上都过度相关** ✗
- **沿 y（行间）0.54 vs 参照 0.15** ✗ → **颜色在行间连贯 = 行条带** ✓ **与你截图里的品红/青横条纹完全吻合** ✓
- **沿 x（行内）0.87 vs 参照 0.55** ✗ → **颜色在行内也过于平滑 = 大尺度斑块而非纹理** ✓
- **且参照是降采样截图**（降采样**抬高**相关性 ✗）→ **原始参照的相关性更低，差距更大** ✓

**→ "没色"的准确机制**：**色度幅度不小（94.7 ≥ 参照 60.5），但它是【大尺度、行相干的斑块】，
而人眼把这种结构读成"灰底上的彩条"而不是"图像的颜色"** ✓✓

### 4.3 这个结构指向什么机制

| 候选 | 是否吻合"大尺度 + 行相干" |
|---|---|
| 固定像素位移（≤20 px） | **不吻合** ✗ 位移会产生**尖锐**的错位，不是平滑斑块 ✓ |
| **超过 20 px 的大位移** | **吻合** ✓ G 与 R 采到图像**不同区域** → 差值是**大尺度平滑图案** ✓✓ |
| 逐通道低频增益/偏置失配 | **吻合** ✓ 也会产生大尺度差 ✓ |
| 逐像素估计噪声 | **不吻合** ✗ 那会产生**不相关**的小尺度噪声 ✓（与 §4.1 相反 ✗）|

**→ 最可能是"G 与 R 采到了图像的不同区域，位移大于 20 px"** ✓✓
**而 §1.1 说的"δ_GR 测量被趋势主导"恰好也指向这一点**：
**若两者真是同一内容、只差几像素，趋势不会那么强** ✗

## 5. 三通道采样起点与标准对比（报告第 5 项）

```
  通道  相对同步起点(ms)  采样间距(ms, 相邻)
  G             -277.98                 —
  B             -138.24            139.74
  R               10.50            148.74

  标准间距: sep(1.50) + scan(138.24) = 139.74 ms
  实测 G→B 139.74 ms ✓  = 标准 ✓
```

- **G→B = 139.74 ms，与标准完全一致** ✓

  → `B起点 → R起点 = scan + sync + porch = 138.24 + 9 + 1.5 = 148.74` ✓✓ **完全一致** ✓

**→ 三通道采样起点与标准 Scottie S1 布局逐项吻合** ✓✓
