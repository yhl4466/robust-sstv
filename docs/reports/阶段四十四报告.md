```

  交叉（解码 G vs 真值 X）: vs R -0.006 · vs G 0.998 · vs B 0.002

  R/G/B  plain 0.997 / detrendLine 0.033–0.045 / diff 0.022–0.029 / PSNR 30.30–31.88
```

### 1.1 ★ 三条结论

| 观察 | 含义 |
|---|---|
| **`plain` 0.997–0.998，PSNR 30.3–33.2 dB** ✓ | **解码是准确的** ✓ 与照片 30.50 dB 完全一致 ✓✓ |
| **`diff` 在平滑内容上崩到 0.02–0.60** ✗ | **差分指标对平滑内容是灾难性的** ✓✓ |
| **`detrendLine` 同样会毁掉平滑内容**（极低频 0.443 ✗、灰度斜坡 0.033 ✗）| **"去趋势"这一类变换都不能用于此目的** ✓ |
| **灰度斜坡 PSNR 31.26 dB** ✓ | **与照片 30.50 dB 同量级 → 解码准确，矛盾消失** ✓✓ |

### 1.2 机理（为什么差分毁掉平滑内容）

对周期 `P` 的正弦，一阶差分把幅度乘以 `2·sin(π/P)` ✗：
- `P = 90 px` → **0.07 倍** ✗
- `P = 209 px` → **0.030 倍** ✗
- `P = 600+ px` → **0.010 倍** ✗

**而白噪声经差分只降 `√2`（≈0.71）** ✓ → **信噪比下降 20–40 倍** ✓✓
**→ 这就是 0.33–0.60 的全部来源** ✓
