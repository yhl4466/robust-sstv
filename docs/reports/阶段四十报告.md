## 1. 去趋势后 G−R 互相关的结果（报告第 1 项）

### 1.1 方法

对每行的 `g(x)`、`r(x)` 先做**一阶差分** `g'(x) = g(x+1) − g(x)`（同 `r'`）✓
再在 **±160 px** 内做零均值归一化互相关 ✓
**一阶差分移除趋势** → 上一轮"峰值随 |δ| 单调升高、锁在边界"的机制被消除 ✓

### 1.2 结果

```
G−R: 中位 -21 px · MAD 0 · 均值 -21.8 · 极值 -148..155 · 峰值相关中位 0.518
G−B: 中位   0 px · MAD 0 · 均值  -2.8 · 极值 -160..155 · 峰值相关中位 0.515
G−R 落在搜索边界(|δ|≥150)的行数: 1/256  ✓ 未锁边界
```

### 1.3 三条判读

| 观察 | 含义 |
|---|---|
| **锁边界从 247/256 降到 1/256** ✓ | **去趋势确实消除了伪影** ✓ 方法有效 ✓ |
| **中位 −21 px 且 MAD = 0** ✓✓ | **256 行位移完全一致 → 系统性几何错** ✓（非随机、非抖动）|
| **峰值相关中位 0.518** ✓ | **去趋势后 G 与 R 仍然相关** ✓（> 0.3 ✓）→ **不是"完全无关"，是"错位后仍相似"** ✓ |

**对任务书判据的对应**：
- "δ_GR 集中在某个非零值 → G 与 R 有系统性大位移" ✓✓ **成立**（−21 px，MAD 0）
- "峰值相关都很低（< 0.3）→ 频率映射问题" ✗ **不成立**（0.518 ✓）

## 2. 位移量级判定（报告第 2 项）

```
G−R 精确中位 -21 px · G−B 精确中位 0 px
一行 = 320 px；Scottie S1 的 G→R 时间间距 = 288.48 ms
判定: 21 px（行内像素级）→ 像素索引错 ✗
```

### 2.1 量级分析

| 量 | 值 | 说明 |
|---|---|---|
| **位移** | **−21 px** | 远小于 320 ✓ 且不接近 320 ✓ |
| **像素时间** | 432.0 µs | S1 |
| **位移对应时间** | **21 × 432 = 9.07 ms** | **≈ 同步脉冲 9 ms** ✓✓ |
| 槽起点差（若为通道级） | 320 px | 未观察到 ✓ |

**→ 判定：行内像素级错位，不是槽起点错** ✓
**→ `chanOffsets` 的时间间距是对的（阶段三十九已验证），无需改动** ✓

### 2.2 ⚠️ 符号的方向需要下一轮确认

我的 `xcorr(a, b, d) = corr(a[i], b[i+d])` ✓ 峰值在 **d = −21** ✓
→ `g[i] ≈ r[i−21]` ✓ 即 **R 的特征出现在更小的索引处 → R 领先 G 约 21 px** ✓
**但"领先/滞后"的物理解释依赖 `STARTS` 的定义方向** ✓
（`g(x)` 对应 G 槽第 x 像素 ✓ `r(x)` 对应 R 槽第 x 像素 ✓ 两者**采样时间朝同一方向递增** ✓
故 R 的内容在时间上**早** G 约 9 ms ✗）
**→ 下一轮应直接用"把 R 的行整体平移 ±21 px 后重算色度"来验证方向** ✓（比符号推理可靠 ✓）

### 2.3 与 9 ms 的巧合值得记下，但**不作结论**

**9.07 ms ≈ 同步脉冲 9 ms** ✓ 这是一个**有量纲意义的整数关系** ✓
但它**可能**是巧合 ✓ **本轮不据此推断机制** ✓（本项目反复因"纸面推演替代实测"而误判 ✗）
**只在报告里记录这个数字关系，作为下一轮的检验目标** ✓

## 3. 逐通道低频失配检验（报告第 3 项）

```
  方案              σ(G−R)  σ(L)   σ(G−R)/σ(L)  σ(G−B)/σ(L)
  原样                 95.4   65.8       1.4498       0.7220
  各通道减行均值          93.0   53.2       1.7479       0.8676
```

**减均值后色度比【升高】20.6%** ✗
→ **色度不来自"每通道整体偏移"** ✓✓
**机制**：减行均值移除了每通道的 DC 分量，而 σ(L) 因此下降更多（65.8 → 53.2）✗
→ 比值反而升高 ✓ 说明**色度能量主要在逐像素变化里，不在通道 DC 差里** ✓

**结论**：**"通道间低频增益/偏置失配"这一候选被否证** ✓
（与 §1 的"系统性像素位移"结论一致 ✓ 位移不是 DC 失配 ✓）
