## 3. 统一导航栏的实现方式（报告第 3 项）

**单点来源 + 双标记块**：导航由 `nav-partial.js` 生成，注入时用 `NAV:BEGIN/END` 包住；**每页标题与页内交叉链接用独立的 `PAGEHEAD:BEGIN/END` 块**。这样导航块本身在四页**逐字节相同**（一致性断言因此可用最强形式），而页标题仍可各异。

```html
<!-- NAV:BEGIN (...) -->
<header class="site-nav">
  <div class="wrap nav-inner">
    <a class="brand" href="index.html">Robust SSTV</a>
    <input type="checkbox" id="navToggle" class="nav-toggle-cb" aria-hidden="true">
    <label for="navToggle" class="nav-toggle-btn" aria-label="展开导航菜单">菜单</label>
    <nav class="nav-links" aria-label="主导航">
      <a href="index.html" class="active" aria-current="page">首页</a>
      <a href="embed-image.html">图片隐藏</a>
      <a href="tech.html">技术报告</a>
    </nav>
    <div class="badge-local" id="backendBadge" title="当前后端模式">local</div>
  </div>
</header>
<!-- NAV:END -->
```

- **当前页高亮**：`class="active"` + `aria-current="page"`
- **移动端折叠**：**纯 CSS checkbox 方案**（`≤700px` 显示"菜单"、`≥701px` 强制展开）。选它而非 JS，因为 `file://` 下最稳，且三个页面本来不加载任何脚本
- **`#backendBadge` 保留**（`js/app.js:683` 写入它、`browser-e2e.js:277` 读取它）
- **tech.html 的导航来自生成器**：手改会被下次 `gen-tech-html.js` 覆盖
