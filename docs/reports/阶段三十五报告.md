## 1. 标定接入的实现方式（报告第 1 项）

`tests/diagnose-calibrated.js`。从解码报告的 `calibration` 白名单读取两个值 ✓

```js
const scale = cal.scale, offsetHz = cal.offsetHz;
const calF = (f) => (f - offsetHz) / scale;      // 原始 → 标称（与解码器 calF 同式）
```

**全部频率映射都改为先 `calF` 再比较** ✓：同步探针、前导探针、三槽频率、三槽灰度、
prominence 联合分布 ✓

### 1.1 打印出的标定值

```

offsetHz = -184.90670747257718
  即 1200 Hz 标称 对应 原始 1131.82 Hz
     1500 Hz 标称 对应 原始 1461.00 Hz
     2300 Hz 标称 对应 原始 2338.82 Hz
headerScale = 0.989805941752063

leaderFreqHz = 1899.91            ← ✓ 几乎正是 1900
```

## 2. 标定验证结果（报告第 2 项）—— **AC2 未达标**

### 2.1 直接测同步音（探针锚在 `ref + 4 ms`，4 ms 窗，限带 900–1600 Hz）

```
原始同步音频率: 中位 1093.6 Hz (MAD 67.37, 极值 -42892..16657)
同步音 prominence: 中位 3.82 (MAD 1.15)
标定后同步音频率: 中位 1165.13 Hz (MAD 61.40, 极值 -38921..15349)
** 标称 1200 Hz，标定后偏差 -34.87 Hz (-2.906%) **
=> 标定后仍偏离 1200 Hz ✗
```

**两点必须说明**：
- **极值 −42892 .. 16657** ✗ —— 那是**无信号行**的读数（噪声峰），中位与 MAD 才反映主体 ✓
- **MAD 61–67 Hz** 很大 ✗ —— 同步音的**逐行估计很不稳**，这不是一个干净的 1200 Hz 峰 ✗

### 2.2 ⚠️ 三个互相矛盾的频率尺度（**必须统一，否则一切免谈**）

| 来源 | 隐含的"1200 Hz 原始频率" | 相对标称 |
|---|---|---|
| **解码器 HEADER 拟合** | `0.989806×1200 + 19.282 = **1207.05 Hz**` | **+0.59%** ✓ 几乎无搬移 |
| **我的同步探针（实测）** | **1093.6 Hz** | **−8.87%** ✗ |
| **解码器同步拟合（被采用的标定）** | `1.097274×1200 − 184.907 = **1131.82 Hz**` | **−5.68%** ✗ |

**三者互相矛盾，最大分歧达 113 Hz** ✗✓

**且 HEADER 拟合说"几乎没有搬移"** ✓ —— 这与**阶段三十四的"搬移 12.9%"直接冲突** ✗
**而阶段三十四的那个数字来自槽内读数、从未探过同步音** ✗
→ **阶段三十四的"搬移 12.9%"结论应予否定** ✓（我的测量方式有缺陷）

**同时，`syncResidualRms = 20822.7` 说明"同步拟合"这个标定来源本身不可信** ✗
→ **被实际应用的那个标定（来自同步拟合）很可能是错的** ✗✓
**而更可信的 HEADER 拟合（leader 1899.91 ✓）却只被用于 `afcMode:'affine'` 的一个分支** ✗

## 6. 搬移来源分析（报告第 6 项）—— **结论：很可能没有 12.9% 的搬移**

| 检查 | 结果 |
|---|---|
| MP4 音频流（ffprobe） | `aac (LC), 48000 Hz, stereo, 188 kb/s` ✓ 容器声明 **48 kHz** ✓ |
| 时长 | MP4 162.53 s vs 抽出音频 162.496 s ✓ 一致 ✓ |
| 若为采样率不匹配 | 48000/44100 = **1.088** ✗ 与观测到的任何比值都不符 ✗ |
| 若为播放速度变化 | 时间轴应同步变化 ✗ 但时间轴正常（427.750 ms = 标称的 99.89%）✗ |
| **解码器 HEADER 拟合** | `leaderFreqHz = 1899.91` ✓ **几乎正是 1900** → **没有搬移** ✓ |
| 我阶段三十四的依据 | 来自**槽内读数**，**从未探同步音** ✗ → **依据不成立** ✗ |

**⇒ 结论**：**没有证据支持"频率被搬移 12.9%"** ✗
**阶段三十四的那个数字是我的测量伪影** ✓ **该结论否定** ✓
**真实情况更可能是**：**槽位置不对，探到了同步音（~1200 Hz）附近的区域** ✓✓
（§3 的直方图把 204/256 行集中在 **1000–1200 Hz**，而 **1200 正是同步音** ✓）
