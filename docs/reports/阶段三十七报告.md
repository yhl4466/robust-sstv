## 1. 暴力 DFT 探针的实现（报告第 1 项）

`tests/diagnose-brutedft.js`。对候选频率**直接做内积取最大** ✓

```js
function bruteDFT(w, lo, hi, step) {
  let best = -1, bf = NaN;
  const dw = 2*Math.PI*step/SR, cStep = Math.cos(dw), sStep = Math.sin(dw);
  for (let f = lo; f <= hi; f += step) {
    let re = 0, im = 0;
    const w0 = 2*Math.PI*f/SR;
    let c = Math.cos(w0), s = Math.sin(w0), ci = 1, si = 0;
    for (let i = 0; i < w.length; i++) {
      re += w[i]*ci; im -= w[i]*si;
      const nc = ci*c - si*s, ns = si*c + ci*s; ci = nc; si = ns;   // 增量相位器，无三角函数
    }
    const m = Math.sqrt(re*re + im*im);
    if (m > best) { best = m; bf = f; }
  }
  return { hz: bf, mag: best };
}
```

**两级扫描**：4 Hz 粗扫 → 在胜者 ±4 Hz 内 0.25 Hz 细扫 ✓
**关键工程点**：用**增量相位器**代替内层的 `cos/sin` 调用 ✓
→ 一次探测约 `1400/4 + 32` ≈ **382 个候选 × 51 采样** ✓ 足够在 256 行 × 3 槽上跑完 ✓
